# 픽셀 다이어트 RPG

식단·운동·체중을 기록하면 레벨이 오르는 픽셀 RPG 다이어트 점검 페이지.

- `index.html` — 누구나 쓰는 공유용 페이지. 기록은 브라우저(localStorage)에만 저장돼요.
  - 캐릭터 성별·눈·얼굴형·헤어 등 꾸미기
  - 키·몸무게 BMI로 체형 5단계(매우 마름 · 약간 마름 · 보통 · 통통 · 뚱뚱) 반영
  - ⚡ 빠른 입력: `1118 (수) 아침 : 곰곰 퀵오트밀 50g, 풀무원 그릭 허니 요거트 90g` 처럼 붙여넣으면 음식·양을 알아듣고, 목록에 없는 음식은 대략 칼로리를 넣어 저장

GitHub Pages: Settings → Pages → Branch `main` / root 로 켜면 `https://<아이디>.github.io/pixel-diet-rpg/` 에서 열려요.
